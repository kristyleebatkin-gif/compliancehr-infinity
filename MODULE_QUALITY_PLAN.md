# ComplianceHR — Module-by-Module Quality Audit & Completion To-Do List

Goal: keep every existing resource, tool, form, log, register, template, report and export already built in each module — remove nothing — then verify and complete every module to the highest standard: visually stunning, artistic, modern, fast, accurate, and fully connected to the person, profile, subject and Document Vault.

---

## PART 1 — PLATFORM-WIDE STANDARDS (apply and verify in EVERY module)

Every module must pass this universal checklist:

### 1.1 Visual design (state-of-the-art, artistic, modern)
- [ ] PageHeader with the module's fixed accent colour, icon, title, subtitle and audit button.
- [ ] StatCard row with bold, saturated, bright colours and key live numbers.
- [ ] SectionCard "ink-on-glass" surfaces with gradients, blur and shadows.
- [ ] Vibrant, semantically correct status badges (centralised statusTone).
- [ ] Editorial typography (Fraunces headings, Manrope body) throughout.
- [ ] Responsive layout (mobile + tablet + desktop), loading states, empty states.
- [ ] Consistent spacing, tabs and card grids — nothing plain or unfinished.

### 1.2 Data entry, storage and accuracy
- [ ] Full create, view, edit, delete, save on every record type in the module.
- [ ] Every record stores: date, time, person who logged it, subject/type, notes.
- [ ] Search, filter and sort on the server (no client-side filtering of loaded lists).
- [ ] Every field of data entered lands in the correct module, topic and subject.
- [ ] All data is connected to the right person/profile and displayed on their profile page.

### 1.3 Documents, forms, logs, templates and registers
- [ ] Every form is prefillable and auto-stamps date, time and person.
- [ ] Every module has its required registers/logs fully implemented and populated.
- [ ] Templates library available for quick-start of each record type.
- [ ] Uploaded files route automatically to the correct profile and the Document Vault.

### 1.4 Export, print, share and send
- [ ] CSV export of the register (all columns, correct data).
- [ ] Branded PDF per record AND for the full register.
- [ ] Print-ready layout.
- [ ] Email share/send via Communication Centre or professional email with correct recipients.
- [ ] Copy/link share where useful.

### 1.5 Branded document presentation (every PDF, form and report)
- [ ] Company name and logo in the header.
- [ ] Professional date and accurate subject line.
- [ ] All usual business details (ABN, address, phone, email, NDIS number).
- [ ] Business key contacts at the end of the document.
- [ ] Footer: business name, logo, mission, vision, and privacy/confidentiality disclosure.
- [ ] Every item placed perfectly — clean tables, aligned columns, consistent tones.

### 1.6 Compliance in every module
- [ ] A compliance audit checklist covering every item in the module.
- [ ] A compliance audit report (branded, with corrective action register).
- [ ] Live compliance tracker strip showing what is in date / due / overdue.
- [ ] Two-minute express audit workflow works in the module.

### 1.7 Notifications, reminders and alerts
- [ ] Expiry/overdue scanning wired to the automated compliance expiry scan.
- [ ] Reminders and alerts displayed in-module and surfaced on the dashboard attention panel.
- [ ] Communication records logged for every alert or notification sent.

### 1.8 People, teams, permissions and privacy
- [ ] Every profile (staff/participant) shows its team list; only agreed team members plus admin and management can see it.
- [ ] Users & permissions matrix matches the module (accurate role access).
- [ ] Privacy and confidentiality respected: RLS rules verified per module.
- [ ] All communication is recorded, stored, logged and entered in the correct subject and topic.
- [ ] Updates flow daily and as changes are made (live subscriptions or refresh on entry).
